# Kalkulator Obligacji
Kalkulator do porównywania opłacalności obligacji skarbowych i obliczania zysków

## Kompilacja

Wymaga jedynie kompilatora C i make.
```bash
make
```

## Działanie

Program pozwala na wybór rodzaju obligacji, czasu inwestycji i kwoty inwestowanej.
Obliczana jest całkowita wartość wygenerowanych odsetek, ile wyniesie podatek oraz jaki będzie całkowity zysk.
